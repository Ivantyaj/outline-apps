# Outline Split для Android

Это локальный форк официального Outline Client. Поддержка ключей `ss://` и `ssconf://`, включая конфигурацию Outline YAML, оставлена штатной.

Android-сборка также принимает транспорт `$type: singbox` с JSON-конфигурацией, содержащей `outbounds` и `route.final`. Для профиля с Shadowsocks, VLESS/REALITY и `urltest` используется sing-box 1.12.13. Остальные разделы sing-box пока отклоняются явно. Серверные адреса и секреты в репозиторий не добавлены: приложение получает их по вашему динамическому ключу при подключении.

## Как пользоваться

1. Установите APK `Outline Split` и добавьте в него свой ключ доступа. Приложение имеет отдельный идентификатор и может стоять рядом с официальным Outline. Сохранённые в официальном приложении ключи автоматически не переносятся.
2. Откройте меню → **Раздельное туннелирование**.
3. Выберите один из режимов:
   - **Все приложения через VPN** — обычная работа Outline.
   - **Выбранные приложения мимо VPN** — нужные приложения используют обычное подключение телефона.
   - **Только выбранные приложения через VPN** — остальные приложения используют обычное подключение.
4. Для Android Auto оставьте включённым показ системных приложений, найдите `com.google.android.projection.gearhead`, отметьте его в режиме «Выбранные приложения мимо VPN» и нажмите **Сохранить**.

При изменении правил активное VPN-подключение ненадолго перезапускается. Правила сохраняются после перезапуска телефона. Если выбранное приложение удалено, его правило остаётся в настройках и заработает снова после установки.

## Сборка

Ветка `split-tunneling` собирается на GitHub Actions с помощью workflow **Build Outline Split APK**. Готовый тестовый APK доступен в артефактах запуска под именем `outline-split-android-debug`. Локальная сборка: `npm run action client/src/cordova/build android`; требования перечислены в `client/src/cordova/android/README.md`.

Тестовый APK подписан отладочным ключом сборочной среды. Для постоянных обновлений нужна собственная стабильная подпись. APK предназначен для установки вручную, без публикации в Google Play.

При установке новой сборки вместо прежнего тестового APK Android может потребовать сначала удалить старое приложение, так как подпись отладочных сборок на GitHub Actions меняется. Перед удалением сохраните ключ: после переустановки его нужно добавить и настроить список исключений заново.

В Android-сборку включён [sing-box](https://github.com/SagerNet/sing-box) под GPLv3. Текст лицензии хранится в `third_party/sing-box/LICENSE`.
